Config Language Translator (вариант №1)

Инструмент командной строки для учебного конфигурационного языка.
Читает исходный текст из стандартного ввода, транслирует его в TOML
и сохраняет по пути, указанному ключом `-o/--output`.

Возможности

- Многострочные комментарии `(comment ... )`
- Двоичные числа `0b...`
- Словари `{ имя : значение, ... }`
- Константные объявления `имя := значение;`
- Вычисление выражений в префиксной форме `?[+ x 1]`
- Функции `abs()`, `sqrt()`

Установка

```bash
make install
